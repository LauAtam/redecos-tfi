# Redeco: Red de compras comunitarias.

Trabajo Final Integrador - Tecnicatura Universitaria en Programación (UTN FRC).

## Estructura del Monorepo
Este repositorio contiene todo el código fuente del MVP:
- `/backend`: API RESTful desarrollada con NestJS y conectada a Supabase.
- `/frontend`: Progressive Web App (PWA) desarrollada con Angular 19 e Ionic.
