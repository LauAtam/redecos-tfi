# Testing Capabilities

| Category | Tool | Command |
|----------|------|---------|
| Test Runner | Jest | `npm test` |
| E2E Testing | Jest | `npm run test:e2e` |
| Coverage | Jest | `npm run test:cov` |
| Linter | ESLint | `npm run lint` |
| Formatter | Prettier | `npm run format` |
| Type Checker | TypeScript | `npx tsc` |

**Strict TDD Mode**: Active (`strict_tdd: true`)
